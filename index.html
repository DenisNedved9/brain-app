🧮 Základní operace

V Pythonu můžeme provádět základní matematické operace. Zde jsou některé z nich:

    + – sčítání (např. 3 + 2 = 5)
    - – odčítání (např. 5 - 2 = 3)
    * – násobení (např. 4 * 2 = 8)
    / – dělení (např. 8 / 2 = 4.0)
    // – celočíselné dělení (např. 7 // 2 = 3)
    % – zbytek po dělení (např. 7 % 2 = 1)
    ** – umocňování (např. 2 ** 3 = 8)
